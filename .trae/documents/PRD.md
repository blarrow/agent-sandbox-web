# Agent Sandbox 项目官网 - 产品需求文档

## 1. 产品概述

Agent Sandbox 是一个专为 AI Agent 开发者设计的沙箱测试平台官网，旨在展示平台的核心理念、功能特性和技术架构。

- **核心目的**：为开发者提供一个安全、可控的环境来测试和部署 AI Agent，实现快速迭代和高效开发
- **目标用户**：AI/ML 工程师、后端开发者、产品经理以及对 AI Agent 开发感兴趣的开发者
- **市场价值**：降低 AI Agent 开发门槛，提供一站式解决方案，加速 AI 应用落地

## 2. 核心功能

### 2.1 页面结构

| 页面 | 模块 | 功能描述 |
|------|------|----------|
| 首页 | Hero 区域 | 大标题 + 副标题 + CTA 按钮 + 动态背景 |

| 首页 | 代码示例 | 简洁的集成代码展示 |

### 2.2 功能模块详情

#### Hero 区域
- 主标题："Build AI Agents with Confidence"
- 副标题："安全的沙箱环境，强大的调试工具，让你的 AI Agent 开发更高效"
- CTA 按钮："开始使用" / "查看文档"
- 动态粒子/网格背景效果

1. **安全隔离** - 进程级沙箱隔离，保护你的生产环境

3. **工具集成** - 支持 50+ 常用工具和 API
4. **灵活部署** - 支持云端和本地部署

#### 架构图
- 可视化展示：用户代码 → Sandbox Engine → 执行环境 → 结果输出
- 简洁清晰的流程图设计

#### 代码示例
- 一段展示如何快速集成的代码片段
- 语法高亮 + 复制功能

## 3. 设计风格

### 3.1 视觉风格
- **主题**：深色科技风 (Dark Tech)
- **主色调**：#0A0A0F (深黑背景)
- **强调色**：#00D9FF (科技蓝) + #FF6B35 (活力橙)
- **辅助色**：#1A1A2E (深紫灰) + #16213E (深蓝灰)
- **文字色**：#FFFFFF (主文字) + #94A3B8 (次级文字)

### 3.2 字体选择
- **标题字体**：Space Grotesk (现代科技感)
- **正文字体**：Inter (清晰易读)
- **代码字体**：JetBrains Mono (等宽代码)

### 3.3 布局设计
- **最大宽度**：1280px 居中布局
- **间距系统**：基于 8px 网格
- **卡片圆角**：16px
- **按钮圆角**：8px

### 3.4 动画效果
- 页面加载时的渐入动画 (staggered fade-in)
- 鼠标悬停时的微交互
- 背景粒子/网格动态效果
- 滚动触发的视差效果

## 4. 响应式设计

- **桌面端**：1200px+ 完整展示
- **平板端**：768px-1199px 双栏布局
- **移动端**：<768px 单栏堆叠

## 5. 技术选型

- **框架**：React 18 + TypeScript
- **构建工具**：Vite
- **样式方案**：Tailwind CSS
- **动画库**：Framer Motion
- **图标库**：Lucide React
