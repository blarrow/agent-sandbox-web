# Agent Sandbox 官网

Agent Sandbox 的官方网站，展示平台功能、使用方法和示例。

## 功能特性

- 🎨 现代化、响应式设计
- 📱 移动端友好
- ⚡ 流畅的动画效果
- 🔍 SEO 优化
- 🎯 清晰的信息架构

## 文件结构

```
/
├── index.html      # 主页面
├── styles.css      # 样式文件
├── script.js       # JavaScript 交互
└── README.md       # 项目说明
```

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 或使用本地服务器：
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js
   npx serve
   ```

## 技术栈

- HTML5
- CSS3 (使用 CSS Grid 和 Flexbox)
- Vanilla JavaScript
- Google Fonts (Inter)
